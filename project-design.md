# Дизайн Telegram-бота "Таро-справочник"

## Summary

Создаем Telegram-бота для начинающих тарологов. В v1 бот работает только как справочник: пользователь выбирает карту из 78 карт Таро и получает простое толкование.

В v1 не входят расклады, энциклопедия, история пользователей, админка, изображения карт и перевернутые значения. Эти возможности закладываются как будущие расширения.

## Key Design

- Стек: `Python 3.12`, `aiogram 3.x`, файловое хранение контента в `JSON`.
- Запуск: локально для разработки, на небольшом VPS для релиза через long polling.
- Навигация: inline-кнопки Telegram, без ручного ввода текста.
- Основной путь: `Главное меню` -> `Справочник карт` -> `Старшие/Младшие арканы` -> `Масть` -> `Карта` -> `Толкование`.
- Для каждой карты показываем: эмодзи, название, краткое значение, совет, любовь, работа, финансы.
- На каждом уровне есть кнопки `Назад` и `В главное меню`.

## Architecture

- `handlers`: команды `/start`, главное меню, обработка callback-кнопок.
- `navigation`: построение меню арканов, мастей и списков карт.
- `content`: загрузка и валидация файлов с 78 картами.
- `formatting`: сборка Telegram-сообщения с толкованием карты.
- `config`: токен бота, режим запуска, пути к файлам контента.
- База данных в v1 не используется, потому что бот не хранит пользовательские данные.

## Data Model

Для каждой карты нужны поля:

```json
{
  "id": "major_fool",
  "group": "major",
  "suit": null,
  "name": "Шут",
  "emoji": "🃏",
  "summary": "Краткое значение карты",
  "advice": "Совет карты",
  "love": "Толкование в любви",
  "work": "Толкование в работе",
  "finance": "Толкование в финансах"
}
```

Для будущих релизов можно добавить необязательные поля `reversed` и `image_path`, но в интерфейсе v1 их не показывать.

## Error Handling

- Если пользователь вводит текст, бот предлагает вернуться к кнопкам справочника.
- Если карта не найдена, бот показывает понятную ошибку и кнопку `В главное меню`.
- Если файл контента поврежден, техническая ошибка логируется, пользователю показывается нейтральное сообщение.
- При старте бот проверяет, что загружены все 78 карт, нет дублей `id`, и обязательные поля заполнены.

## Test Plan

- Проверить загрузку всех 78 карт.
- Проверить, что старшие арканы показывают 22 карты.
- Проверить, что каждая масть младших арканов показывает 14 карт.
- Проверить выбор каждой карты и формат сообщения.
- Проверить кнопки `Назад` и `В главное меню` на всех уровнях.
- Проверить поведение при текстовом вводе вместо кнопок.
- Критерий готовности: пользователь без ввода текста может дойти до любой карты и получить толкование по всем пяти блокам.

## Assumptions

- Основной язык бота: русский.
- Тон текстов: простой, понятный, обучающий.
- В v1 вместо изображений карт используются эмодзи.
- Контент для всех 78 карт подготовлен до релиза.
